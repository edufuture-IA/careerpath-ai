# CareerPath AI


## Descripción

CareerPath AI es una aplicación web que conecta estudiantes con opciones de carrera y programas académicos mediante recomendaciones personalizadas. La plataforma facilita la toma de decisiones vocacionales considerando perfiles, intereses y aptitudes de cada usuario.

## ✨ Características

- 📱 **Perfiles de Usuario**: Estudiantes, profesores e instituciones con roles diferenciados
- 🤖 **Orientación Vocacional**: Recomendaciones inteligentes basadas en análisis de perfiles
- 🏫 **Gestión de Instituciones**: Registro y administración de universidades y programas
- 👨‍💼 **Panel Administrativo**: Control centralizado de usuarios y contenido
- 🔐 **Autenticación Segura**: Sistema de login con autorización por roles
- 📱 **Interfaz Responsiva**: Diseño moderno en escritorio y móvil

## 🔑 Funcionalidades Principales

### Para Estudiantes
- Explorar carreras y universidades
- Recibir recomendaciones personalizadas
- Gestionar perfil académico
- Contactar instituciones

### Para Profesores
- Gestionar estudiantes
- Crear recomendaciones
- Monitorear progreso
- Acceso a reportes

### Para Administradores
- Gestión completa de usuarios
- Control de instituciones
- Gestión de carreras
- Reportes y análisis

## 🔐 Seguridad

Sistema de autenticación con roles:
- **Admin**: Acceso total
- **Profesor**: Gestión de estudiantes
- **Estudiante**: Acceso a recomendaciones
- **Institución**: Gestión de programas
